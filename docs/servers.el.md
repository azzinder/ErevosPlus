# Οι servers με τους οποίους μιλά το Erevos

Κάθε server που μπορεί να φτάσει το Erevos, τι βλέπει ο καθένας και τι κρατά. Στα αγγλικά: [servers.md](servers.md).
Οι λεπτομέρειες, για κάθε είδος αντιπάλου, είναι στο [μοντέλο απειλών](threat-model.md) (στα αγγλικά). **Χωρίς
ανεξάρτητο έλεγχο**: η σελίδα λέει τι είναι φτιαγμένος να κάνει ο κώδικας, όχι τι έχει ελέγξει κάποιος.

Κανένας από αυτούς τους servers δεν μπορεί να διαβάσει τι γράφεις: μηνύματα, φωτογραφίες, αρχεία και κλήσεις είναι
κρυπτογραφημένα από άκρο σε άκρο, πάνω στα τηλέφωνα. Ό,τι μπορεί να δει ένας server είναι **ποιος συνδέεται, πότε και
πόσο**.

## Ο server σου

Ο server κρατά τα μηνύματα ώσπου να τα πάρει το άλλο τηλέφωνο. Τον διαλέγεις εσύ: της LPHL (`erevos.lphl.nekten.eu`),
της κοινότητάς σου, έναν που τρέχεις μόνος σου (το πρόγραμμα έρχεται με το Erevos), ή κανέναν, για τηλέφωνα που
συναντιούνται μόνο κοντά.

**Βλέπει:**

- Τις **διευθύνσεις IP** που γράφουν στις ουρές σου, και τη δική σου όταν τις διαβάζεις. Με το Tor ανοιχτό, μια έξοδο
  του Tor αντί για τη δική σου.
- **Πότε** έρχονται και πότε παίρνονται τα μηνύματα, και πότε περιμένει το τηλέφωνό σου.
- **Μεγέθη**: κάθε μήνυμα έχει ένα από τέσσερα σταθερά μεγέθη, και τα αρχεία πηγαίνουν σε κομμάτια σταθερού μεγέθους.
- **Πόσα και πότε γράφει η κάθε επαφή**, γιατί κάθε επαφή που κράτησες γράφει σε δική της ουρά. Όχι ποια είναι,
  πέρα από τη διεύθυνση που γράφει.
- Αν ένα πακέτο είναι μήνυμα που διαβάζει άνθρωπος ή κουβέντα ανάμεσα στα τηλέφωνα, και πότε χτυπά μια κλήση.
- Με τις ειδοποιήσεις της ιστοεφαρμογής ενώ είναι κλειστή: μια διεύθυνση push για τις ουρές σου.

**Δεν βλέπει** τι γράφεις, το όνομά σου, τον αριθμό σου, τα ονόματα των επαφών σου ή τη λίστα των επαφών σου.

**Τι κρατά ο server της LPHL, και για πόσο** (ο ίδιος πίνακας είναι στον οδηγό της εφαρμογής, στη **Διαφάνεια**):

| Τι | Για πόσο |
|---|---|
| Μηνύματα που περιμένουν, κρυπτογραφημένα από άκρο σε άκρο | Ώσπου να τα πάρει το τηλέφωνο, 14 μέρες το πολύ |
| Φωτογραφίες και αρχεία, κρυπτογραφημένα, σε κομμάτια | Ώσπου να τα πάρει το τηλέφωνο, 14 μέρες το πολύ |
| Μηνύματα για αργότερα, κρυπτογραφημένα | Ώσπου να έρθει η ώρα τους |
| Ουρές: τυχαία αναγνωριστικά χωρίς όνομα | Ώσπου να μείνουν αχρησιμοποίητες 180 μέρες |
| Γραμμές πρόσβασης: το SHA-256 του κλειδιού (token) κάθε τηλεφώνου, και ένα όνομα (τυχαίο, ή το όνομα χρήστη LPHL) | Ώσπου να αφαιρεθεί η γραμμή |
| Διευθύνσεις push της ιστοεφαρμογής | Ώσπου να κλείσουν οι ειδοποιήσεις στην ιστοεφαρμογή |

**Δεν γράφει αρχείο συνδέσεων**, και ο web server μπροστά του δεν κρατά αρχείο πρόσβασης από τις 24 Οκτωβρίου 2026.
Τα σφάλματα γράφονται, και ένα σφάλμα μπορεί να αναφέρει μια διεύθυνση. Ο φάκελος του server **αντιγράφεται κάθε μέρα**,
με τα μηνύματα που περιμένουν πάντα κρυπτογραφημένα. Το μηχάνημα φιλοξενείται στη **Hetzner**, που τρέχει και το δίκτυό
του.

Ένας server που τρέχει άλλος κρατά ό,τι διαλέξει αυτός: το πρόγραμμα είναι το ίδιο, οι ρυθμίσεις και τα αρχεία του είναι
δικά του. Ένας **Σπιτικός server** (**Ρυθμίσεις** → **Server και δίκτυα** → **Σπιτικός server**), όπου γράφουν οι επαφές
όσο ο δικός σου δεν απαντά, βλέπει ό,τι και ο server σου, για όσα περνούν από αυτόν.

Το **Σβήσε με από παντού** (**Ρυθμίσεις** → **Απόρρητο και ασφάλεια**) σβήνει ό,τι κρατούν οι servers για έναν χώρο,
και τον σταματά.

**Όποιος βρίσκεται ανάμεσα** στο τηλέφωνό σου και στον server (το δίκτυό σου, ή όποιος πάρει πιστοποιητικό για το όνομα
του server): αφού ο server αποδείξει στο τηλέφωνό σου το δικό του κλειδί, βλέπει μόνο ότι συνδέεσαι, πότε και πόσο.

## Ο server της επαφής σου

Όταν η επαφή σου έχει άλλον server, ο δικός σου δίνει τα μηνύματά σου στον δικό της. Ο server της βλέπει τον server σου, όχι
τη διεύθυνσή σου. Ο δικός σου βλέπει σε ποιον server στέλνεις, όχι την ουρά. Δύο διαχειριστές που συγκρίνουν τα αρχεία
τους μπορούν πάντως να ταιριάξουν μηνύματα από την ώρα.

## Server κλήσεων

Ένας server μπορεί να έχει δίπλα του έναν **server κλήσεων** (server TURN, της LPHL έχει). Οι κλήσεις τότε περνούν από
αυτόν, και κανένα τηλέφωνο δεν μαθαίνει τη διεύθυνση IP του άλλου.

- **Βλέπει** τις διευθύνσεις IP των δύο τηλεφώνων στην κλήση, πότε αρχίζει, πόσο κρατά και πόσα περνούν.
- **Δεν βλέπει** την κλήση: φωνή και εικόνα είναι κρυπτογραφημένες από άκρο σε άκρο ανάμεσα στα τηλέφωνα (DTLS-SRTP),
  με κλειδιά που ελέγχονται μέσα από την κρυπτογραφημένη συνομιλία.
- Εξυπηρετεί μόνο τηλέφωνα που δέχεται ο server.
- Οι κλήσεις **δεν περνούν ποτέ από το Tor**.

Χωρίς server κλήσεων, μια κλήση συνδέεται μόνο απευθείας, και τότε **το άλλο τηλέφωνο βλέπει τη διεύθυνση IP σου**.

## Servers του Nostr

Στο Android, τα κείμενα πηγαίνουν και μέσα από δημόσιους servers του Nostr (**ανοιχτό, εκτός αν το κλείσεις**, στις
**Ρυθμίσεις** → **Server και δίκτυα** → **Nostr**), ώστε ένα μήνυμα να φτάνει και όταν ο server δεν απαντά. Οι πρώτοι
είναι οι `relay.damus.io`, `nos.lol` και `relay.primal.net`, και μπορείς να τους αλλάξεις. **Δεν είναι δικοί μας**:
κρατούν ό,τι θέλουν, για όσο θέλουν.

- Κάθε κείμενο τυλίγεται (NIP-59) με ένα κλειδί φτιαγμένο μόνο για εκείνο το μήνυμα, για ένα κλειδί που έφτιαξε η
  επαφή σου μόνο για εκείνη τη συνομιλία.
- **Ένας server του Nostr βλέπει** τη διεύθυνση IP σου (μια έξοδο του Tor, με το Tor ανοιχτό), ένα μέγεθος με γέμισμα, μια
  ώρα πισωγυρισμένη ως μία ώρα, και το κλειδί της συνομιλίας: καταλαβαίνει ποια μηνύματα πάνε στην ίδια συνομιλία,
  **όχι ποιοι είναι μέσα**. Βλέπει επίσης ότι ένα τηλέφωνο διαβάζει μαζί τα κλειδιά πολλών συνομιλιών.
- Ένα κείμενο που δεν φάνηκε να έφτασε μέσα σε πέντε λεπτά πηγαίνει και από τον server σου.

## Ο server της ιστοεφαρμογής

Το `erevos-web.lphl.nekten.eu` δίνει τα αρχεία της ιστοεφαρμογής, που είναι υπογεγραμμένα: η εφαρμογή αρνείται να τρέξει
οτιδήποτε χωρίς υπογραφή. Βλέπει τη **διεύθυνση IP του προγράμματος περιήγησης** που τη φορτώνει ή την ενημερώνει. Δεν
κρατά αρχείο πρόσβασης από τις 24 Οκτωβρίου 2026. Ο **Έλεγχος για ενημερώσεις** στο Android ζητά επίσης από εκεί την
υπογεγραμμένη δήλωση της τελευταίας έκδοσης.

## Υπηρεσίες push

Μόνο για την **ιστοεφαρμογή**, και μόνο με τις ειδοποιήσεις ενώ είναι κλειστή ανοιχτές. Η υπηρεσία push του
προγράμματος περιήγησης (Apple, Google, Mozilla ή Microsoft) παίρνει ένα push πάντα του ίδιου μεγέθους, κρυπτογραφημένο
για το πρόγραμμα περιήγησής σου.

- **Βλέπει** ότι ήρθε ειδοποίηση ή χτύπησε κλήση, και πότε: ένα push κάθε 15 δευτερόλεπτα το πολύ.
- **Δεν βλέπει** τι ήρθε ή από ποιον.

Η εφαρμογή Android **δεν χρησιμοποιεί καμία υπηρεσία push**: περιμένει η ίδια στον server.

## GitHub

Το Erevos δεν ψάχνει ποτέ μόνο του για ενημερώσεις, γιατί ένας τακτικός έλεγχος θα έλεγε στο GitHub κάθε μέρα ότι
αυτή η συσκευή έχει Erevos. Μόνο όταν πατάς **Έλεγχος για ενημερώσεις** διαβάζει το `version.json` από το GitHub. Το
GitHub τότε βλέπει τη διεύθυνση IP σου και ότι μια συσκευή ελέγχει. Το ίδιο ισχύει όταν κατεβάζεις μια έκδοση από το
GitHub.

## Ιστοσελίδες, για προεπισκοπήσεις συνδέσμων

Τις προεπισκοπήσεις συνδέσμων τις φτιάχνει **το τηλέφωνο που στέλνει**, την ώρα που στέλνει, και μόνο όταν είναι
ανοιχτές. Το τηλέφωνο φέρνει τη σελίδα μόνο του, χωρίς να κρατά cookies. Η σελίδα βλέπει τη διεύθυνση IP του
τηλεφώνου και πότε, όπως θα έβλεπε από ένα πρόγραμμα περιήγησης, και τίποτα για το σε ποιον πάει το μήνυμα. Με τον
δικό τους διακόπτη Tor ανοιχτό, η σελίδα έρχεται μόνο μέσα από το Tor. Όσο ο χώρος στέλνει τα πάντα μέσα από το Tor,
δεν φτιάχνεται καμία προεπισκόπηση.

## Άλλοι

- **Tor** (Android, κλειστό εκτός αν το ανοίξεις): ο πρώτος κόμβος του Tor βλέπει τη διεύθυνση IP σου, όχι πού πας.
  Η έξοδος βλέπει πού πας, όχι ποιος είσαι. Το χρησιμοποιούν μόνο οι συνδέσεις στους servers και στους servers του Nostr.
- **Ο server των αντιγράφων ασφαλείας σου**, αν έβαλες αυτόματα αντίγραφα: παίρνει κρυπτογραφημένα αρχεία με τυχαία
  ονόματα. Μπορεί να τα ξεχωρίσει από το μέγεθος, να τα μετρήσει, και να δει περίπου πόσα κρατά κάθε αντίγραφο.
- **Ραδιόφωνο** στη Συλλογή: ο σταθμός που ακούς βλέπει τη διεύθυνση IP σου, όπως με κάθε πρόγραμμα. Η αναζήτηση
  σταθμών ρωτά το Radio Browser.
- **Σύνδεση LPHL** (Authentik): βλέπει κάθε σύνδεση με LPHL, που δίνει στο τηλέφωνό σου κλειδί για τον server.
- **SMS όταν δεν δουλεύει τίποτε άλλο** (Android, κλειστό εκτός αν το ανοίξεις): η εταιρεία κινητής βλέπει ποιος
  αριθμός έγραψε σε ποιον, πότε και πόσα SMS, ποτέ τις λέξεις.

- **Μοντέλα φωνής και μετάφρασης** (Android, μόνο όταν τα ζητήσεις): κατεβαίνουν από τον web server του LPHL, ή από
  έναν φάκελο web που ορίζεις εσύ (**Λήψη από άλλον server…**). Εκείνος ο server βλέπει τη διεύθυνση IP σου και ποιο
  μοντέλο παίρνεις· το Erevos ελέγχει κάθε αρχείο με το αποτύπωμα που ξέρει και απορρίπτει όποιο διαφέρει.

## Οι δικοί σου servers αντί για του LPHL

Τίποτα από τα παραπάνω δεν χρειάζεται το LPHL. Μέσα στην εφαρμογή: δικός σου server ή της ομάδας σου (**Νέα συνομιλία**
→ **Δεν έχω πρόσκληση** → **Έχω δικό μου server**· οι κλήσεις έρχονται μαζί του), server WebDAV για τα αντίγραφα
ασφαλείας και τη Συλλογή, φάκελος web για τα μοντέλα, ή κανένας server (**Ξεκίνα χωρίς server**). Μια σελίδα επαφής ή
μια πρόσκληση με SMS από άλλον web server διαβάζεται όταν την επικολλήσεις ή τη σαρώσεις· μόνο ο server του build και
του LPHL ανοίγουν μόνοι τους στο Erevos.

Όποιος φτιάχνει το Erevos για μια κοινότητα μπορεί να αλλάξει και τι προτείνει πρώτα η εφαρμογή, με δύο ρυθμίσεις του
build (`app/lib/servers.ts`): `EREVOS_WEB_ORIGIN` (ο web server με τις σελίδες επαφής και πρόσκλησης και τα μοντέλα)
και `EREVOS_START_RELAY` (ο server όπου προτείνεται η είσοδος σε τηλέφωνο χωρίς server). Οι ειδοποιήσεις για τις
εκδόσεις του ίδιου του Erevos μένουν στον server του LPHL, γιατί πάνε μαζί με το κλειδί των εκδόσεών του, και τις ρωτούν
μόνο τηλέφωνα με server του LPHL.

## Ό,τι δεν φτάνει κανένας server

Ένας server δεν διαβάζει τα μηνύματά σου, αλλά όποιος βλέπει **και τις δύο άκρες** του internet μαζί μπορεί να
ταιριάξει μηνύματα από την ώρα και το μέγεθος: το Erevos δεν στέλνει ψεύτικη κίνηση για κάλυψη. Και όποιος κρατά το
**ξεκλείδωτο τηλέφωνό σου** βλέπει ό,τι έχει ο ανοιχτός χώρος. Τι ανοίγει ένα κινητό ή κλειδί που κλάπηκε:
[stolen-key.el.md](stolen-key.el.md).
